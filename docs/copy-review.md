## 확인한 접근성

- 6개 장 모두 Tab 키 10~11번이면 주 버튼에 닿아요.
- 만화 그림은 모두 `aria-label`이 있어요. 1장 그래프에는 이번에 붙였어요.
- 작은 글씨 대비 부족은 발견되지 않았어요.
- 3장 일별 그래프 범례 아이콘(recharts가 만드는 svg)에는 설명이 없어요. 범례 글자가 옆에 있어서 그대로 뒀어요.

## 판단이 필요한 부분 → 후속 결정 (2026-10-20 11:17)

- 5장 "번호표"와 6장 "대기표/대기판"이 비슷하게 들림 → 6장을 **맛집 메뉴판**으로 바꾸고, 대기판도 메뉴판으로 바꿨어요 (주소 `/cache`는 그대로).
- 6장 흐름 표시와 Redis 명령 개수가 자세히 밖에 있음 → 화면에는 "메뉴판 확인 → 없음 → 주방에 물어봄 → 메뉴판에 5초 동안 적어 둠"처럼 쉬운 말로, 개발 용어 흐름(`GET → miss → SELECT → 행 → SET EX 5`)과 명령 개수 표는 개발자용 자세히로 옮겼어요. 움직이는 그림은 그대로예요. 몰림 그림 아래 줄은 "파란 점: 주방에 안 간 손님 · 빨간 점: 주방으로 간 손님"으로.
- 1장 만화의 "100석", "의자는 100개뿐" → 본문과 같이 "표 100장"으로. 카드 아래에 "돌릴 때마다, 그리고 컴퓨터와 설정에 따라 숫자가 달라져서 아래 결과와 다를 수 있어요"라는 한 줄을 붙였어요.
- 파비콘이 없어 404 → 손그림 버튼 `app/icon.svg`와 공유 미리보기 그림 `app/opengraph-image.png`, OG·트위터 카드 문구를 넣었어요.
- 첫 화면의 작성자 자리(사진·이름·이력서·연락처)는 아직 비어 있어요.
